**Projeto Dashboard de Vendas - Power BI**

Este repositório contém um dashboard interativo desenvolvido para análise de performance de vendas e controle de devoluções de produtos tecnológicos. O projeto foca em transformar dados brutos em insights visuais para facilitar a tomada de decisão estratégica.

**📊 Visão Geral do Dashboard**

O dashboard foi estruturado para responder a perguntas críticas de negócio, como faturamento mensal, produtos com maior índice de devolução e distribuição geográfica das vendas.

**🛠️ Tecnologias e Ferramentas**

Power BI: Construção dos visuais e dashboards interativos.

Power Query (M): Limpeza e tratamento dos dados.

DAX (Data Analysis Expressions): Criação de medidas calculadas para KPIs como Faturamento Total e Quantidade de Devoluções.

Modelagem de Dados: Relacionamento entre tabelas de Vendas e Devoluções.

**📈 Principais Insights Extraídos**

Produto Estrela: O iPhone destaca-se como o produto mais vendido em ambos os cenários analisados.

Atenção às Devoluções: Identificação do SmartWatch e Android como produtos com volumes significativos de devolução, permitindo uma investigação sobre a qualidade ou logística destes itens.

Distribuição Geográfica: Análise das vendas concentrada em grandes centros como São Paulo, Rio de Janeiro e Curitiba.

Sazonalidade: Acompanhamento do faturamento mensal variando entre R$ 3,5 Mi e R$ 8,8 Mi, permitindo identificar picos de demanda.

**🚀 Como Visualizar**

Faça o download do arquivo .pbix presente neste repositório.

Certifique-se de ter o Power BI Desktop instalado em sua máquina.

Abra o arquivo para interagir com os filtros e gráficos.
